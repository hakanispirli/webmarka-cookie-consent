# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be respectful and welcoming, whatever someone's experience level, background or identity.
- Give and accept constructive feedback gracefully. Focus on what is best for the community.
- Harassment, insults, personal attacks, trolling, and publishing others' private information are not acceptable.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that violate this code of conduct, and may temporarily or permanently ban contributors.

Report unacceptable behavior privately to the maintainers through a [private security advisory](https://github.com/hakanispirli/webmarka-cookie-consent/security/advisories/new), or contact the maintainer through their [GitHub profile](https://github.com/hakanispirli). All reports are reviewed promptly and kept confidential.
